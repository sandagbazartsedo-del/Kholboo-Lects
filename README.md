# Холбоо, дохиоллын техникийн хэрэглээ

Сонсогчид лекц бүрийн дараа орж давтах хичээлийн вэбсайт.

## Шинэ лекц нэмэх

1. `lectures.js` файлыг нээгээд харандаа (✏️) дүрс дээр дарна.
2. Сүүлийн лекцийн `{ ... }` блокийг хуулж, ард нь таслал (`,`) тавиад буулгана.
3. Дугаар, гарчиг, агуулгыг нь солино.
4. **Commit changes** дарна. Хэдэн минутын дараа сайт шинэчлэгдэнэ.

Бусад файлыг (`index.html`, `style.css`, `app.js`) өөрчлөх шаардлагагүй.
